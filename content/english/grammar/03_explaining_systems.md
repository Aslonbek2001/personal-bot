# Explaining systems

- Zero and First Conditional - describing system behavior ("If the cache is empty, the service calls the database")
- Second Conditional - discussing alternative architectures
- Passive voice (present and past) - writing technical documentation
- Passive voice with modals and Present Perfect - deployment notes ("The index has been rebuilt")
- Relative clauses: who, which, that, where - describing components of a RAG pipeline
- Linking words: because, although, however, therefore - explaining technical decisions
- Purpose and result: to, in order to, so that, so - explaining why code exists
- Comparatives and superlatives - comparing models, libraries and approaches
